# 手语打分网页 MVP V3 运行说明

更新时间：2026-05-22 23:20:00 CST

## 变化

V3 保留 v2 的“查看参考”按钮和可选参考视频窗，同时增加测评前准备倒计时：

- 点击“采集并打分”后，用户视频区域覆盖显示 `3、2、1、开始`。
- 倒计时结束后才正式采集视频帧并提交后端评分。
- 旧版 `5080` 和 v2 `5081` 都保留，便于对比。

## 端口

V3 使用：

```text
127.0.0.1:5082
```

`5082` 只负责 v3 静态前端、参考视频和轻量 API 代理；它不会启动新的 `MediaPipe Holistic` worker。评分请求会统一转发到共享后端：

```text
http://127.0.0.1:5080
```

## Windows 访问

在 Windows PowerShell / CMD 中建立隧道：

```bash
ssh -N -L 5082:127.0.0.1:5082 wuyangcheng@<远端服务器地址>
```

如果 SSH 有自定义端口：

```bash
ssh -N -L 5082:127.0.0.1:5082 -p <ssh端口> wuyangcheng@<远端服务器地址>
```

然后打开：

```text
http://127.0.0.1:5082
```

对比版本：

```text
v1: http://127.0.0.1:5080
v2: http://127.0.0.1:5081
v3: http://127.0.0.1:5082
```

## 口径

V3 只调整前端交互节奏，评分机制仍复用当前 demo-only prototype similarity。当前输出仍不是正式用户评分阈值。
