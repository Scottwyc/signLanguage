# 小红书卡片渲染库调研

> 保存时间：2026-08-30 19:30（北京时间）
> 维护者：运维（signL8）
> 任务：为 MTP 投机解码实验分享制作 6 张 3:4 竖版（1242x1656）小红书文字卡片

## 1. 调研目标

把 MTP A/B 实验发现（POC 加速 vs 真实拖慢 52%）渲染成小红书风格的文字卡片图。
要求：中文字体清晰、分辨率 ≥1080x1440、亮色渐变+白底、大字号、留白合理、可嵌入 fig6 数据图。

## 2. 候选方案与调研结论

### 2.1 HTML → 图片（playwright / chromium 路线）——❌ 不可行

- **playwright**：本机未安装（`ModuleNotFoundError: No module named 'playwright'`）。
- **浏览器内核**：`which chromium / chromium-browser / google-chrome` 均无输出，无可用浏览器。
- **结论**：HTML/CSS 排版→截图这条最省事的路线在本机走不通；装 playwright + 下载浏览器内核成本高、且受网络（GFW）限制，放弃。

### 2.2 现成小红书卡片生成器（GitHub 调研）——❌ 无合适工具

- GitHub 搜索「xiaohongshu card generator / 小红书 卡片 生成」，仅找到：
  - **YangUper/video2xhsnote**（约 40 star）：视频转图文笔记工具，面向视频切片，不是纯文字卡片生成器，依赖重、场景不符。
- **结论**：没有可直接复用的「纯文字 + 数据图」小红书卡片生成器，需自研渲染脚本。

### 2.3 其他 Python 绘图库

| 库                     | 说明                                     | 是否采用         | 理由                                                             |
| ---------------------- | ---------------------------------------- | ---------------- | ---------------------------------------------------------------- |
| **PIL / Pillow** | 轻量、逐像素可控、直接绘制文字/形状/贴图 | ✅**采用** | 最轻量、无需浏览器、对中文+形状+贴图完全可控，PIL 9.0.1 本机已装 |
| matplotlib             | 强于图表，弱于「海报式」文字排版         | ❌               | 适合画 fig6 这类图，不适合做卡片版式                             |
| imgkit                 | 依赖 wkhtmltochrome（HTML→图）          | ❌               | 需额外装 wkhtmltochrome，本质还是 HTML 路线                      |
| weasyprint             | HTML/CSS→PDF/图                         | ❌               | 依赖重（cairo/pango），且仍需 HTML 排版                          |
| reportlab              | PDF 排版                                 | ❌               | 面向 PDF，做 PNG 卡片不顺手                                      |

## 3. 最终方案：PIL/Pillow 9.0.1 直接绘制

### 3.1 选型理由

1. **零额外依赖**：本机已装 PIL 9.0.1，无需装浏览器/HTML 引擎，规避 GFW 下载风险。
2. **完全可控**：逐像素绘制渐变背景、圆角面板、胶囊徽章、箭头、统计块，版式精确到像素。
3. **中文 + 贴图**：Noto CJK SC 字体直接渲染中文；fig6 用 `Image.paste` 等比缩放嵌入。
4. **可复用**：脚本带参数（可指定卡片编号），后续改数据/换配色可直接复用。

### 3.2 字体方案（关键踩坑）

| 字体                     | 路径                                                                  | 用途         | 备注                                                                                                 |
| ------------------------ | --------------------------------------------------------------------- | ------------ | ---------------------------------------------------------------------------------------------------- |
| Noto Sans CJK SC Bold    | `/usr/share/fonts/opentype/noto/NotoSansCJK-Bold.ttc`（index=2）    | 标题/强调    | ttc 需指定`index=2` 才是简体子字体                                                                 |
| Noto Sans CJK SC Regular | `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`（index=2） | 正文         | 同上                                                                                                 |
| SimHei（备选）           | `/home/wuyangcheng/.fonts/SimHei.ttf`                               | 备用中文字体 | 未作为主字体                                                                                         |
| NotoColorEmoji           | `/usr/share/fonts/truetype/noto/NotoColorEmoji.ttf`                 | 彩色 emoji   | **PIL 9.0.1 无法加载**（CBDT 位图字体，仅 136px，FreeType truetype 报 `invalid pixel size`） |

**emoji 处理**：因 NotoColorEmoji 无法在 PIL 9.0.1 加载，卡片改用 **Noto CJK SC 内置的等宽符号**（★▲●○■□→←↑↓≈≠×÷✓⚠❗❓◆▶ 等）+ **PIL 自绘形状**（圆、箭头、色块）替代彩色 emoji，保证视觉表现且不依赖彩色 emoji 字体。

### 3.3 渲染脚本

- 路径：`/data/WYC/signLanguage/work/reports/xiaohongshu_share_mtp_20260830/scripts/render_cards.py`
- 用法：`python3 render_cards.py`（全部 6 张）或 `python3 render_cards.py 1 3 5`（指定编号）
- 输出：6 张 PNG 到输出文件夹根目录，分辨率 1242x1656（3:4 竖版）

## 4. 结论

- **最终采用**：PIL/Pillow 9.0.1 直接绘制。
- **核心理由**：本机无 playwright/chromium（HTML 路线不可行）、无现成卡片生成器（需自研）、PIL 零依赖且对中文/形状/贴图完全可控。
- **主要坑**：NotoColorEmoji 为 CBDT 位图字体，PIL 9.0.1 无法加载 → 用 CJK 等宽符号 + 自绘形状替代彩色 emoji。
